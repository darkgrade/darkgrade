Darkgrade Studio is a desktop app (Electron + React) that puts everything in [Darkgrade Link](/link) behind a UI and a fully local voice assistant.

## Run it

```bash
bun install
bun run studio
```

Plug in a PTP camera over USB — Studio auto-connects on launch.

<Warning>
    **macOS** spawns `ptpcamerad` (older versions: `PTPCamera`; mass-storage mode: `mscamerad`) the moment a camera
    enumerates, and it claims the PTP interface before anything else can. A single kill is not enough — launchd
    respawns the daemon and macOS clobbers camera access again. Studio kills these daemons **every second for the
    entire app lifetime**, plus immediately before each connection attempt (with one retry). If a connection still
    fails with an access or busy error, use the **Free camera** button — or say *"fix the camera"*.
</Warning>

## Features

- Connect / disconnect, with vendor auto-detection (Sony ⍺, Nikon Z, Canon EOS R, generic PTP)
- ISO, shutter speed, and aperture — read and set
- Image capture with instant preview, saved to a folder you choose
- Live view streaming
- Video recording
- Camera storage browser with per-file and bulk download
- Live PTP event log

## Voice control

Speech recognition (Whisper via transformers.js), intent parsing, and spoken replies all run **on-device** — nothing leaves your machine. The model (~80 MB) downloads once on first launch and is cached offline afterwards.

- **Push-to-talk:** hold <kbd>Space</kbd>, speak, release
- **Always listening:** toggle on and prefix commands with the wake word — *"hey darkgrade, take a photo"*

Example commands: *"set ISO to 800"*, *"ISO sixty four hundred"*, *"shutter to 1/250"*, *"shutter to two seconds"*, *"aperture to f/2.8"*, *"take a photo"*, *"start live view"*, *"start recording"*, *"cut"*, *"list files"*, *"download everything"*, *"what are my settings"*.

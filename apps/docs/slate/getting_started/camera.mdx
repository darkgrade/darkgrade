---
title: "Cameras"
description: "The Camera class provides a high-level interface for interacting with PTP-compatible cameras. It automatically selects the appropriate vendor-specific implementation (Sony, Nikon, Canon, or Generic) based on the connected device."
---

## Import

```typescript
import { Camera } from '@darkgrade/slate'
```

## Constructor

```typescript
constructor(options?: CameraOptions)
```

### Parameters

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| **options** | `CameraOptions` |  | Optional configuration for the camera instance. |
| **options.logger** | `Partial&lt;LoggerConfig&gt;` |  | Optional logger configuration; console capture and terminal rendering are off by default for `Camera`. |
| **options.device** | `DeviceDescriptor` |  | Device descriptor for the camera. If provided, the appropriate vendor-specific implementation will be selected automatically. |

## Methods

### getCapabilities, getShutterSpeed, setShutterSpeed, setControl

Use the [shared control model](/slate/getting_started/controls) for application
settings. It exposes only observed properties and re-checks current choices before
writes. Shutter speed and shutter angle share the `shutterSpeed` id (`exposureTime`
is a search alias); converting units requires the actual frame rate. Native angle
mode is preserved.

```typescript
const { controls } = await camera.getCapabilities()
const shutterSpeed = await camera.getShutterSpeed()
await camera.setShutterSpeed('180°', { framesPerSecond: 25 })
await camera.setControl('colorTemperature', 5600)
```

These writes require writable, advertised values; the examples do not establish
support on every camera or in every shooting mode.

### discover

List attached USB cameras without opening one.

```typescript
static async discover(): Promise&lt;DiscoveredCamera[]&gt;
```

### connect

Open the camera: select the attached body, its vendor driver and a session.

```typescript
async connect(options?: ConnectOptions): Promise&lt;void&gt;
```

| Option | Type | Required | Description |
| ------ | ---- | -------- | ----------- |
| **observeOnly** | `boolean` |  | Read without changing any setting. Sony keeps its dial priority and saved image destination. Default `false`. |
| **device** | `DeviceDescriptor` |  | The body to open. If not provided, uses the device from the constructor options. |

### getInfo


### Protocol access

Raw PTP operations, property reads and writes and the standard property inventory left `Camera`.
For bench work they are on `protocolSession(camera)` from the unsupported
`@darkgrade/slate/protocol` entry: `send`, `get`, `set`, `readValue`, `getStandardPropertyStates`
and `setStandardProperty`, typed by the registries' codecs and sharing the Camera's session.
Nothing there is confirmed the way `Camera` operations are.

Application controls use `getCapabilities()` and the typed setters (`setIso`, `setAperture`,
`setShutterSpeed`), which read the same standard properties on a generic or Olympus camera.
Vendor recognition alone does not prove that a body publishes ISO, aperture, focus, or capture
operations:

```typescript
const { controls } = await camera.getCapabilities()
if (controls.iso?.writable && controls.iso.allowedValues?.includes('ISO 400')) {
  await camera.setIso('ISO 400')
}
```

The physically tested Olympus E-PL5 MTP mode publishes battery level and writable date/time, but no exposure, focus, or remote-capture control. Newer Olympus bodies automatically expose any standard properties they actually advertise.

### on

Register an event handler. `settingsChanged` fires when a setting changes on the camera and
`mediaAdded` when a new photo or clip lands; a raw `EventDefinition` from the protocol registry is
for bench work.

```typescript
on(event: 'settingsChanged' | 'mediaAdded', handler: () => void): void
on(
  event: EventDefinition,
  handler: function
): void
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| **event** | `EventDefinition` | ✓ | The event definition to listen for. |
| **handler** | `function` | ✓ | The handler function to call when the event occurs. |

### off

Unregister an event handler.

```typescript
off(
  event: EventDefinition,
  handler?: function
): void
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| **event** | `EventDefinition` | ✓ | The event definition to stop listening for. |
| **handler** | `function` |  | Optional handler function. If not provided, all handlers for the event are removed. |

### getAperture

Get the current aperture, such as `'f/2.8'` or `'Auto'`.

```typescript
async getAperture(): Promise&lt;Aperture&gt;
```

### setAperture

Set the aperture and return the value the camera read back. The value must be one the camera
offers now (`getCapabilities().controls.aperture.allowedValues`).

```typescript
async setAperture(value: Aperture): Promise&lt;Aperture&gt;
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| **value** | `Aperture` | ✓ | `'f/'` and the f-number, such as `'f/4'`, or `'Auto'`. |

### getShutterSpeed

Get the current shutter speed, such as `'1/250'`, `'30"'`, `'180°'` or `'Bulb'`.

```typescript
async getShutterSpeed(): Promise&lt;ShutterSpeed&gt;
```

### setShutterSpeed

Set the shutter speed and return the value the camera read back. A shutter angle and a duration
convert to each other only with the actual frame rate.

```typescript
async setShutterSpeed(value: ShutterSpeed | ExposureTime, context?: { framesPerSecond: number }): Promise&lt;ShutterSpeed&gt;
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| **value** | `ShutterSpeed \| ExposureTime` | ✓ | `'1/250'`, `'30"'`, `'180°'`, `'Bulb'`, or an exposure-time object. |
| **context** | `{ framesPerSecond: number }` |  | The actual frame rate, required to convert between angle and duration. |

### getIso

Get the current ISO, such as `'ISO 800'` or `'Auto'`. Sony's extended and Multi Frame NR
sensitivities keep their own names (`'ISO 51200 (extended)'`, `'Multi Frame NR ISO 800'`).

```typescript
async getIso(): Promise&lt;Iso&gt;
```

### setIso

Set the ISO and return the value the camera read back. On a Sony body with a separate auto/manual
gain switch, Slate switches it as part of the write.

```typescript
async setIso(value: Iso): Promise&lt;Iso&gt;
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| **value** | `Iso` | ✓ | `'ISO 800'`, `'Auto'`, or a Sony extended / Multi Frame NR sensitivity. |

### getExposureMode / setExposureMode

The exposure mode as a word: `'Manual'`, `'Aperture priority'`, `'Shutter priority'`, `'Program'`,
`'Auto'`, `'Flexible priority'` or `'Bulb'`. The setter also accepts `M`, `A`, `S`, `P` and Canon's
`Av`, `Tv`, `Fv`. Photo or video is a separate setting: a Sony body in movie mode reads `'Manual'`
for Movie Manual, and offers only its movie modes.

```typescript
async getExposureMode(): Promise&lt;ExposureMode&gt;
async setExposureMode(value: ExposureMode | ExposureModeAlias): Promise&lt;ExposureMode&gt;
```

### getExposureCompensation / setExposureCompensation

Exposure compensation in stops with a sign and one decimal: `'+0.7'`, `'-1.0'`, `'0.0'`.

```typescript
async getExposureCompensation(): Promise&lt;ExposureCompensation&gt;
async setExposureCompensation(value: ExposureCompensation): Promise&lt;ExposureCompensation&gt;
```

### getMeteringMode / setMeteringMode

The metering mode as a word: `'Multi'` (Canon Evaluative, Nikon Matrix), `'Center-weighted'`,
`'Spot'`, `'Large spot'`, `'Partial'`, `'Average'` or `'Highlight'`.

```typescript
async getMeteringMode(): Promise&lt;MeteringMode&gt;
async setMeteringMode(value: MeteringMode): Promise&lt;MeteringMode&gt;
```

### takePhoto

Takes one photo and resolves only once the camera shows the new file. Photo or video mode is
prepared inside and undone afterwards; the shutter command is never resent.

```typescript
async takePhoto(options?: { autofocus?: boolean; destination?: 'card' | 'computer' }): Promise&lt;Photo&gt;
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| **options.autofocus** | `boolean` |  | Focus before the release. Defaults to `true`. |
| **options.destination** | `'card' \| 'computer'` |  | `card` (the default) keeps it on the card; `computer` also returns its bytes as `data`. |

The photo carries its `mediaId`, `name` and `sizeBytes`, the same id `listMedia()` reports.

### getLiveViewFrame

The current picture as a JPEG, with the camera's focus frames (0–1 from the top-left) and, with
`overlay`, the camera's on-screen info as a PNG. Each call waits for the camera's next frame.

```typescript
async getLiveViewFrame(options?: { overlay?: boolean }): Promise&lt;LiveViewFrame&gt;
```

### startRecording

Gets the camera ready (video mode, card destination), starts, and resolves once the camera reports
recording. Record is sent once and never repeated.

```typescript
async startRecording(): Promise&lt;void&gt;
```

### stopRecording

Stops, waits until a finished clip is on the card, puts the camera back, and resolves to the clip.
Always allowed.

```typescript
async stopRecording(): Promise&lt;Clip&gt;
```

### getRecordingState

```typescript
async getRecordingState(): Promise&lt;'idle' | 'starting' | 'recording' | 'stopping' | 'unknown'&gt;
```

Unknown never counts as idle.

### Card and media

```typescript
async getCardStatus(): Promise&lt;CardStatus[]&gt;
async listMedia(): Promise&lt;MediaItem[]&gt;
async getMediaPreview(id: string, size?: 'thumbnail' | 'preview'): Promise&lt;Uint8Array&gt;
async downloadMedia(
  id: string,
  options?: { onProgress?: (receivedBytes: number, totalBytes: number) => void; signal?: AbortSignal }
): Promise&lt;Uint8Array&gt;
```

Media ids survive a reconnect while the file stays on the card. Nothing on the card is ever
deleted or changed.

## Exports

The vendor driver classes are not part of the main entry. For bench work they are exported, with
the registries and raw PTP access, from the unsupported `@darkgrade/slate/protocol` entry:

- `CanonCamera`
- `GenericCamera`
- `NikonCamera`
- `SonyCamera`

```typescript
import { protocolSession, SonyCamera } from '@darkgrade/slate/protocol'

const driver = protocolSession(camera).driver
if (driver instanceof SonyCamera) console.log(driver.registry.properties.PositionKeySetting.name)
```

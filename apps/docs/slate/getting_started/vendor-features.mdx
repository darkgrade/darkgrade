---
title: "Vendor features"
description: "How Sony, Canon and Nikon settings map to the one Camera API, and the raw access left for bench work."
---

Every setting and operation has one name on every camera. Sony's image quality, Canon's picture
style and Nikon's Picture Control are all `setPictureStyle`; Sony's Flexible Spot is a `Spot`
focus area. A vendor's own word is only a search alias (see the
[shared control model](/slate/getting_started/controls)). Each setting is available only when the
attached body advertises it now: read `getCapabilities()` before building controls.

## Photo, video and zoom settings

```typescript
const { controls, operations, lens } = await camera.getCapabilities()
console.log(controls.photoFormat?.allowedValues, operations?.zoomTo, lens?.focalLengthMillimetres)

await camera.setFocusMode('AF-S')
await camera.setPhotoFormat('RAW+JPEG')
await camera.setJpegQuality('Extra Fine')
await camera.setPhotoSize('Large')
await camera.setAspectRatio('3:2')
await camera.setVideoFormat('XAVC S 4K')
await camera.setDigitalZoom('Off')

// Zoom to a focal length on a power-zoom lens; resolves to where the lens landed.
const landed = await camera.zoomTo(35)
console.log(landed)
```

Every setter accepts only values the attached camera offers now, writes once and resolves to the
value read back. A value the camera refuses is `CameraRefusedError` and nothing changed; a write
the camera never shows is `CameraOutcomeUnknownError` and is never resent.

The physical α6700 validation round-tripped and restored AF-A/AF-S, JPEG/RAW, XAVC S HD/XAVC HS 4K, and 3:2/4:3. Its current mode publishes white balance as display-only. Remote zoom is driven through the Sony zoom-operation control code (`SDIO_ControlDevice` `0xd2dd`, int8 direction). A power-zoom lens is required to move the optical focal length, and some bodies need **Shooting → Zoom → Remote Zoom Speed** enabled.

## Focus

```typescript
await camera.setFocusPoint(0.5, 0.25) // 0–1 from the top-left; focuses there
const focus = await camera.autofocus() // 'acquired', 'not-acquired' or 'unknown'
await camera.nudgeFocus('far', 'small')
await camera.resetFocusPoint()
console.log(focus)
```

On Nikon (validated over USB on Z6 III firmware V2.00) a nudge drives small lens steps in **AF-S**;
AF-F can remain busy and MF rejects the drive. Accepted commands and AF-point placement do not
establish focus lock: only `'acquired'` does.

## Raw vendor access for bench work

Vendor inventories, Canon network state and HDMI output, Nikon event polling and raw events are
protocol access. They are unsupported, follow the vendors' own names, and are not confirmed the way
`Camera` operations are:

```typescript
import { protocolSession } from '@darkgrade/slate/protocol'

const session = protocolSession(camera)
if (session.vendorId === 0x054c) console.log((await session.getSonyPropertyStates()).length)
if (session.vendorId === 0x04a9) console.log(session.getCanonNetworkState().communicationMode)
```

Sony's inventory preserves its mode-aware availability flags: an enabled flag of `2` is
display-only in the current body mode. `setCanonNetworkCommunicationMode(value)` accepts only a
mode advertised by that camera. `getNikonVendorPropertyCodes()` enumerates advertised extended
property IDs (355 on the tested Z6 III); unknown properties are not made writable. Nikon property
access and event polling fall back to legacy operations only on `OperationNotSupported`
(`0x2005`); a property refusal (`0x200a`) remains a refusal.

## Known behaviors

- **Canon keep-alive.** A Canon session sends `KeepDeviceOn` every ten seconds when the body advertises it, so the camera does not sleep mid-session. Pass `new Camera({ keepAlive: false })` to turn this off. No power setting saved on the body is changed.
- **Canon HDMI output.** The tested EOS 80D resets its HDMI live-view mode when its PTP session closes; Slate manages live-view output itself.
- **EOS R6 Mark III movie lever.** With the lever at Movie, the body cannot be put in still mode over PTP (firmware 1.0.1). Set the lever on the camera.
- **Sony files over 4 GiB.** `ObjectInfo` reports the size as `0xffffffff` for these. Slate reads the real size from the object's `ObjectSize` property; a 5.1 GB FX2 original transferred and decoded in full. The α6700 splits recordings at 4 GB instead.
